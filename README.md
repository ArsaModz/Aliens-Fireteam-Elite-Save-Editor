# Aliens: Fireteam Elite Save Editor (PS4/PC)
A free, save editor for *Aliens: Fireteam Elite* on PS4 and PC. Built with C# and WPF (.NET), it handles save decryption and re-encryption automatically so you always get a valid save file.

## 🚀 Key Features

### 👤 Player Stats
* Set Account Level, Account XP, Prestige Level, Prestige XP, and Last Claimed Prestige
* Max out Credits and Rep Scrip instantly
* Set Last Used and Max Unlocked difficulty
* Toggle Hardcore mode
* One-click Max buttons for all rank and resource fields

### 🪖 Classes
* Edit Level and XP for each class individually
* One-click Max selected class or Max All classes at once
* **Add or Remove the Recon class** — the hidden class not normally accessible in standard play

### 🔫 Weapons
* Own or disown any weapon across all categories — Rifle, CQW, Hand Gun, and Heavy
* Edit Level and XP per weapon
* Unlock All / Lock All weapons with one click
* Max selected weapon or Max All owned weapons at once

### 🔧 Attachments
* Own or disown any attachment across all slot types — Armature, Barrel, Magazine, Muzzle, and Optics
* Unlock All / Lock All attachments with one click

### 🧪 Consumables
* Set quantity for any consumable item
* Max selected consumable or Max All at once; Clear All in one click

### 🃏 Challenge Cards
* Set quantity for any challenge card
* Max selected card or Max All; Clear All in one click

### 🎨 Appearances
* Own or disown any cosmetic — Outfits, Head Accessories, Weapon Colors, and Weapon Decals
* Unlock All / Lock All appearances with one click

### 💃 Emotes
* Own or disown any emote
* Unlock All / Lock All emotes with one click (default emotes are always preserved)

### 🔍 Intel
* Unlock or lock any intel entry organized by campaign — UAS Endeavor, Priority One, Giants in the Earth, The Gift of Fire, The Only Way to Be Sure, and Promise of a Flower
* Unlock All / Lock All intel with one click

### 🏆 Achievements
* Unlock or lock any in-game achievement individually
* Unlock All / Lock All achievements with one click

### ⚙️ Misc / Content Unlocks
* Toggle Hardcore Tiering, Hardcore Character Creation, and Prestige unlocks

### 🔄 Save Converter
* **PS4 → PC** and **PC → PS4** save conversion with one click

### 📝 Raw JSON
* View and edit the fully decrypted save data as raw JSON
* Export decrypted JSON to a file for external editing
* Import a JSON file back and have it re-encrypted on save

## 📝 How to Use
1. **Open:** Select your PS4 (`ue4savegame.ps4.sav`) or PC (`char.sav`) save file. Use the **Open PC Save** button to navigate directly to your Steam save folder.
2. **Edit:** Navigate the tabs to modify stats, weapons, appearances, achievements, and more.
3. **Save:** Click **Save File** to write back. The file is re-encrypted automatically.
